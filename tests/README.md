# Validation

Rust engine: run `cargo test` inside `engine` after installing Rust/Cargo.
Flutter UI: run `flutter analyze` and `flutter test` after installing Flutter.

The deliverable was authored in an environment without Flutter, Dart, or Rust SDKs, so executable builds and unit tests could not be run here. Static integrity checks and ZIP verification were completed. An optional Dart fallback lets the application launch even if Rust has not yet been compiled.
